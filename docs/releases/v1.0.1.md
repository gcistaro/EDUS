## v1.0.1 — Refactoring

Internal restructuring of the code, plus a few fixes and robustness improvements. No new physics.

### Refactoring

- `Simulation` has been split into `System`, `Propagator`, `OutputManager` and `MeanField`.
- `DESolver` has been refactored, and its parameters can now be set from input.
- Several functions have been renamed.

### Fixes

- **Tight-binding potentials**: fixed a bug affecting systems with many orbitals.
- **Units**: unknown units, or units of the wrong kind (e.g. an energy unit for a length), now stop the run with a clear error message instead of being silently accepted.

### Improvements

- **Input checking**: variables not recognized in the input file are reported (and discarded), with a suggestion for the closest valid name.
- **Performance**: the DFT is faster, since the phase factors are precomputed and stored.
- **Utilities**: new `utility/laser.py` script for the lasers.

### Changes in numerical results

- The time propagation now uses **RK4 for the first steps** (before switching to AB5), so the propagation is consistent also when the laser is non-zero at the initial time.
  Results can therefore differ slightly from v1.0.0 at the level of numerical accuracy; the test tolerances have been adjusted accordingly.

### Testing

- New regression tests for Si, GaAs and LiF, and a test with a laser that is non-zero at the initial time (`Si_IPA_initialtime`).
