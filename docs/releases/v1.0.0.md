## v1.0.0 — Published version

This is the version of EDUS used in the published work: [arXiv:2608.16226](https://arxiv.org/abs/2608.16226).

Main change: **the screening can now be computed ab initio**.

### New features

- **Ab-initio screening**: the bare and screened Coulomb interactions can be read from file
  (`read_interaction = true`, with `bare_file` / `screen_file`), as matrix elements in the Wannier basis
  on a set of R vectors computed by the KCW code of Quantum ESPRESSO.
  Full HSEX calculations are now possible entirely from first principles.
- **Model Coulomb potentials**: restructured, with the model selectable from input (`coulomb_model`, e.g. Rytova–Keldysh with `epsilon` and `r0`).
- **GPU support**: CUDA implementation of H(t), of the Peierls phase and of the FFTs.
- **Post-processing**: projected DOS and fatbands.
- **Output**: estimated remaining time and progress percentage.

### Implementation notes

- The SEX potential is forced to be Hermitian.

### Build and testing

- Continuous integration with GitHub Actions (Spack build, IPA and HSEX tests on hBN).
- Unit tests with GoogleTest.
- The code can be built without MKL and without MPI; the default build uses MPI and no GPU.
