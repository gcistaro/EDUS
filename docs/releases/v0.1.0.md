## v0.1.0 — First tagged version

This is the first tagged version of the code. It marks the current state of the project as the starting point for versioning.

### Features

- **Density-matrix equations of motion**: the EOM for the density matrix can be solved up to the **HSEX** level (Hartree + screened exchange).
- **IPA from first principles**: the independent-particle (IPA) part can already be computed *ab initio* from the Wannier90 `seedname_tb.dat` file, which provides both the tight-binding Hamiltonian and the position-operator matrix elements.
- **Screening (model only)**: the screening entering the SEX term is currently available only through **model** descriptions. An *ab initio* screening is not implemented yet.

### Implementation notes

- The **position operator** read from `seedname_tb.dat` is **forced to be Hermitian**, i.e. it is symmetrized as r → (r + r†)/2.

### Known limitations

- No *ab initio* screening: HSEX calculations rely on model screening.
