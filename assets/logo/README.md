# EDUS logo

Pixel-art logo of EDUS, drawn with the NES color palette.

| File | Use |
|---|---|
| `svg/edus-logo-horizontal-{dark,light}.svg` | Horizontal logo (icon + wordmark) |
| `svg/edus-logo-vertical-{dark,light}.svg` | Vertical logo (icon above wordmark) |
| `svg/edus-icon-{dark,light}.svg` | Icon only |
| `animated/github-banner.gif` | Animated banner shown in the main README |

`dark` versions are meant for dark backgrounds, `light` versions for light backgrounds.
The SVGs are pixel-exact and scale to any size without blurring.

## Colors

| Role | Dark | Light |
|---|---|---|
| Background | `#000000` | `#FCFCFC` |
| Wordmark | `#FCFCFC` | `#000000` |
| 3D shadow | `#0058F8` | `#3CBCFC` |
| Hexagon / subtitle | `#3CBCFC` | `#0058F8` |
| Orbit | `#940084` | `#940084` |
| Electron | `#F8B800` `#E45C10` `#881400` | same |

## Usage

You are welcome to use the logo to refer to EDUS (papers, talks, posters, websites).
